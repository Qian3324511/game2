# game2 · 布站记 · 县域气象观测网

把《勃艮第城堡》的机制搬进县域气象观测网：六角图板、骰子布点、区域计分。

**在线玩**：https://qian3324511.github.io/game2/

## 玩法

- 图板：37 个六角格的县域图，6 类地类，每格 1–6 点
- 每轮两颗骰，各做一次行动：取装备 / 布点（点数+颜色+相邻三重匹配）/ 上传数据 / 调技术员
- 铺满一片同色区域按格数计分
- 5 阶段 × 5 轮，终局按数据包、经费、技术员结算
- 双人同屏对战 + 单人练习
